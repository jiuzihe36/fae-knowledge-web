按键去抖与 RC 振荡器 应用指南

去抖和振荡器是同一个电路的两种用法：RC 决定「什么时候到」，施密特决定「翻不翻」。 去抖要它「慢，但只翻一次」；振荡器要它「慢到自己能翻回来」。判据、公式、边界都在下面。

全文阈值取自实体页实测表（典型值），所有时间/频率数字都是把阈值代入公式算出来的，不是实测；设计定型必须用 min/max 极值复核，并在样机上量波形。

1. 为什么机械触点必须用施密特

1.1 触点抖动是「一串边沿」，不是一个边沿

金属弹片闭合时先撞、再弹、再撞。电气上表现为在几毫秒的窗口内多次通断，每次通断的宽度从几十微秒到几百微秒不等。整串抖动持续时间随机，跟开关结构、按压力度、使用年限都有关。

实际      ‾‾|_|‾|_|‾‾|_|‾‾‾‾‾‾‾‾‾‾‾‾‾     ← 一次按下，5~20 次通断
普通门    ‾‾|_|‾|_|‾‾|_|‾‾‾‾‾‾‾‾‾‾‾‾‾     ← 每个边沿都翻 → MCU 计 6 次

1.2 普通 CMOS 门在阈值附近是一台「高增益放大器」

普通门只有一个阈值（约 0.5·VCC）。输入在阈值附近时，几毫伏的噪声就能推翻判决；而慢边沿恰好让信号在阈值带里停留最久。结果是：边沿越慢，翻转次数越多——和直觉相反。

数学上，一次翻转需要输入穿过阈值带。普通门的迟滞是 0，所以在阈值点上的任何微小扰动都会变成一次完整翻转。施密特把「一个阈值」换成「两个阈值」：上升要过 VT+，下降要过 VT−，中间 VH 的区间里输出保持不动。这就是「记忆」。

1.3 只加 RC 反而更糟（如果后面是普通门）

RC 低通压制的是幅度，不是次数。它把陡边沿变成缓边沿，等于把信号「泡」在阈值区更久，普通门反而更容易被噪声反复触发。所以：

  • RC 单独用 → 只适合后面接有迟滞的输入；
  • 施密特单独用 → 只解决「判决」，不解决「抖动能量」（抖动幅度接近满幅时，VH 挡不住）；
  • RC + 施密特 → RC 把抖动压到 VH 以内，施密特保证只翻一次。两者缺一不可。

1.4 数据手册的背书

EM74LVC1G14、EM74LVC1G17、EM74HC14、EM74HCS10/11 的特性表都写了同一句：Unlimited rise and fall times（输入转换时间无限制）。这不是营销话术，是「输入可以无限慢」的正式承诺。

对照组很明确：普通门 EM74LVC1G04 的推荐工作条件里写死 Δt/ΔV ≤ 20 ns/V（1.65–2.7 V）/ 10 ns/V（2.7–5.5 V）。按 3.3 V 算，0→3.3 V 的边沿至少要 33 ns 才「在保证范围内」；而 RC 去抖的边沿是毫秒级，比这个上限慢了五个数量级。把 RC 直接接到普通门输入，等于把器件用在规格书明确不保证的区域。

2.4 AHC1G17 的一个坑

AHC1G17 在 3.0 V 供电时 VT+ 最大可达 2.2 V。如果信号摆幅只有 2.5 V（很多低功耗 MCU 的 GPIO），高电平余量只剩 0.3 V，温度一漂就不翻。2.5 V 摆幅请用 LVC，不要用 AHC。

另外：按 datasheet 的 VH min 核算，AHC（0.3 V @3.0 V）和 LVC（0.31 V @3.0 V）几乎一样；AHC 的「宽迟滞」体现在上限（1.2 V vs 0.7 V）。所以「抗噪选 AHC」这句话只在典型条件下成立，按最坏情况算并不会更宽。

2.5 选型决策树

  1. 单键、3.3 V/1.8 V → EM74LVC1G17GV（同相）或 EM74LVC1G14GV（反相）。
  2. 多键、5 V → EM74HC14D（六路，配 10 kΩ 排阻）；要 TTL 阈值收 3.3 V 信号 → EM74HCT14D。
  3. 工业噪声、3.3 V → EM74AHC1G17，但先确认信号摆幅 ≥ VT+ max + 0.5 V。
  4. 要门控/多路 → EM74HCS10（NAND，低电平关断）或 EM74HCS11（AND，低电平关断输出）。
  5. 要振荡器 → 只能用反相施密特（1G14 / HC14）或 NAND 施密特（HCS10）。同相缓冲 1G17 不行。

3. RC 去抖参数怎么算

3.1 拓扑与两个时间常数

最常用接法：R 上拉到 VCC，按键到 GND，C 与按键并联到地，RC 节点直接进施密特输入。

        VCC
         │
       R_p 47 kΩ
         │
   ┌─────┴──────┬─────────────► A  EM74LVC1G17 ──► Y ──► MCU GPIO
   │            │
  SW1          C 0.47 µF
   │            │
  GND          GND

设 τ = R_p·C，则：

按下（C 从 VCC 放电到 VT−）：  v(t) = VCC·e^(−t/τ)
                             t_fall = τ·ln( VCC / VT− )

释放（C 从 0 充电到 VT+）：   v(t) = VCC·(1 − e^(−t/τ))
                             t_rise = τ·ln( VCC / (VCC − VT+) )

公式的假设（不满足就要修正）：开关导通电阻为 0；门输入漏电流可忽略（|II|·R ≪ VH）；C 为理想电容（无 ESR、介质吸收可忽略）；阈值在充放电期间恒定；输出侧负载不反过来改变输入阈值；按键与 C 之间无串联电阻。

把 LVC1G14 的 typ 阈值代进去，得到「时间系数」表——这个表是本文最有用的东西：

VCC t_fall / τ t_rise / τ 不对称比
1.8 V 1.10 0.81 1.35
2.3 V 1.19 0.74 1.61
3.0 V 1.10 0.69 1.58
4.5 V 1.03 0.67 1.54
5.5 V 1.06 0.64 1.66

两个直接结论：

  • 按下比释放慢约 1.6 倍（@3.0 V，1.10τ vs 0.69τ）。原因是 VT+ 与 VT− 并不互补（1.5 V 和 1.0 V 到 VCC 的距离不同）。把电路镜像成「下拉 + 按键到 VCC」只是把这个不对称换了个方向，不会消除。
  • 3.0 V 下用极值算，t_fall 落在 0.88τ–1.23τ，t_rise 落在 0.56τ–0.84τ。做延迟预算用慢角（1.23τ），做「够不够灵敏」检查用快角（0.88τ）。

3.2 两个判据：不误翻 + 响应够快

判据 A（不误翻）：一次抖动脉冲宽度 t_p 内，C 上的跌落不能吃掉整个迟滞带。

ΔV = VCC·(1 − e^(−t_p/τ))  <  VH_min
⇒  τ > t_p / ln( VCC / (VCC − VH_min) )

代入极值：

条件 VH_min 系数 含义
LVC @3.0 V 0.31 V 9.1 × t_p 抖动 100 µs → τ > 0.91 ms
LVC @5.5 V 0.47 V 11.2 × t_p 抖动 100 µs → τ > 1.1 ms
HCS @4.5 V 0.40 V 10.7 × t_p 抖动 100 µs → τ > 1.1 ms

注意区分两个「抖动时间」：单次脉冲 t_p（几十~几百 µs，进上面的公式）和整串抖动 T_b（1~10 ms 量级，决定总响应延迟）。数据手册给的往往是后者，代入前先确认口径。

判据 B（响应延迟）：

按键响应 = T_b + t_fall ≈ T_b + 1.1τ（typ）/ 1.23τ（max）  @3.0 V

人手能感知的延迟约 50 ms，按键体验建议总响应 ≤ 30 ms。

判据 C（漏电流）：高阻节点上，输入漏电流会把工作点顶偏：

ΔV_offset = II · R_p    要求 < 0.1·VH_min

LVC 的 II max = ±1 µA（全温区），typ ±0.1 µA。@3.0 V、VH_min = 0.31 V：

  • R = 47 kΩ → 47 mV（15% VH_min），全温区可接受；
  • R = 100 kΩ → 100 mV（32% VH_min），常温没问题，125 °C 要复核；
  • R = 330 kΩ → 330 mV（超过 VH_min），任何温度都不该用。

结论：R_p 上限 100 kΩ（消费级）/ 47 kΩ（宽温、车规）。

R_p C τ 按下 typ / max 释放 typ / max 用途
10 kΩ 0.1 µF 1.0 ms 1.1 / 1.2 ms 0.69 / 0.84 ms 快速响应键、矩阵键盘扫描
22 kΩ 0.47 µF 10.3 ms 11.4 / 12.7 ms 7.2 / 8.7 ms 通用推荐
47 kΩ 0.47 µF 22.1 ms 24.3 / 27.1 ms 15.3 / 18.6 ms 面板键、长线
100 kΩ 0.1 µF 10.0 ms 11.0 / 12.3 ms 6.9 / 8.4 ms 省容值（C 小、R 大）
100 kΩ 1 µF 100 ms 110 / 123 ms 69 / 84 ms 防误触、长按判定

推荐区间：τ = 10–22 ms（覆盖绝大多数轻触开关），R 取 22–47 kΩ，C 取 0.1–0.47 µF。C 用 X7R 就够（去抖不要求容值精确）；要精确延时才上 C0G，但 0.47 µF 的 C0G 体积和价格都不划算——那种场合应该改方案。

3.4 边界条件

  • C 的放电电流：按下瞬间 C 通过开关放电，峰值只受开关电阻和走线电感限制。C = 1 µF、3 V、开关 50 mΩ，理论上 60 A——实际会打火、烧蚀触点。串电阻的位置决定它影响哪一段，别混：
  • R_s 串在按键与 C 之间：只进入放电回路，放电 τ = R_s·C，充电 τ = R_p·C 不变（§5.2 用这种）；
  • R_s 串在 RC 节点与门输入之间：充放电都要过它，两个 τ 都变成 (R_p + R_s)·C，同时兼顾 ESD 限流，但不限制 C 的放电电流。
  • 典型取 100 Ω–1 kΩ，放电峰值降到 3–30 mA。
  • C 的介质：X7R 在接近额定电压时容值可掉 30%~50%（看厂家 DC-bias 曲线），Y5V 更差。定时用途选 C0G/NP0，或把 X7R 降额到 1/3 额定电压使用。
  • 湿电流：R 太大时触点电流只有几 µA，某些开关（尤其镀银、大功率）要求最小湿电流才能破氧化膜。这类开关要么选低 R（≤10 kΩ）+ 大 C，要么在规格书里确认低电平信号能力。
  • MCU 内部上拉：如果 GPIO 开了内部上拉（典型 20–50 kΩ），它会和 R_p 并联，τ 直接算错。外部有上拉就关内部上拉，或把并联值代进公式。
  • 省成本方案：能软件消抖就别加硬件。硬件 RC + 施密特只在三种场合必要：强干扰现场、低功耗唤醒（MCU 睡着时也要干净边沿）、按键线缆长（>20 cm，易拾噪）。

3.5 精度预算

误差项 对 t_fall 的影响
阈值 min/max 0.88τ~1.23τ（相对 typ −20%/+12%）
R 容差 ±1%（金属膜）~ ±5%（厚膜）
C 容差 + DC-bias C0G ±5%；X7R 未降额可到 −40%
漏电流 折算成阈值偏移 II·R
温度 已含在 min/max 列

结论：去抖时间不要指望优于 ±15%，也不需要。去抖的设计目标是「最坏情况仍然够长」，不是「精确」。用 C0G + 1% 电阻，按 0.88τ 检查灵敏度、按 1.23τ 检查响应延迟，就够了。需要精确延时的场合（比如长按 2 s 开机），把 RC 只当「粗定时 + 去抖」，精确计时交给 MCU。

4. RC 振荡器频率估算与误差来源

4.1 拓扑

反相施密特 + R 从输出反馈到输入 + C 从输入到地。这是唯一能用单门实现的 RC 振荡器拓扑，因为环路里必须有 180° 反相。

              R = 100 kΩ
        ┌──────────────────┐
        │                  │
        │   ┌──────┐       │
        ├───┤A    Y├───────┴──────► f_out
        │   │ 1G14 │
        │   └──────┘
       ─┴─ C = 1 nF
        │
       GND

工作过程：C 从 VT− 充电到 VT+ 期间输出为高（经 R 拉高 C）；越过 VT+ 输出翻低，C 经 R 放电到 VT−；再翻高，循环。迟滞提供的是判决记忆——没有 VH，单门 RC 环路会停在线性区，不起振。

4.2 频率公式

充电（VT− → VT+，输出 VOH）：t1 = RC·ln( (VOH − VT−) / (VOH − VT+) )
放电（VT+ → VT−，输出 VOL）：t2 = RC·ln( (VT+ − VOL) / (VT− − VOL) )

T = t1 + t2 ,  f = 1/T

假设：VOH = VCC、VOL = 0（空载、轨到轨）；阈值在一周期内恒定；R ≫ 输出阻抗；C ≫ C_I + 杂散；漏电流忽略；tpd ≪ T。

令 α = VT+/VCC、β = VT−/VCC，并取 VOH = VCC、VOL = 0：

T = RC · [ ln((1−β)/(1−α)) + ln(α/β) ]

VCC 从式子里消掉了——这是一阶「频率与电源无关」的来源，也是 RC 振荡器唯一的美德。但它只在阈值严格按比例缩放时成立，见 4.3。

  • 同一块板、固定 VCC 下，频率重复性不错（R、C 精度决定）；
  • 换电源电压（比如电池从 4.2 V 掉到 3.0 V），频率会明显变——这对电池设备是致命的。

tpd 0.4%（1 MHz）/ 0.04%（100 kHz） 4.3 ns typ、7 ns max @3.0 V，低频可忽略
电源变化 1.7×（1.8→5.5 V） 见 4.3，不是小数

总账：不校准 ±30%~±50%，校准后可做到 ±10%~±15%。 想再准就得换晶振/陶瓷谐振器，或者用 MCU 定时器。

4.5 适用边界

能用：蜂鸣器驱动、LED 闪烁、上电延时、电荷泵时钟、看门狗「心跳」、玩具/小家电的节奏源。

不能用：UART/SPI/CAN 等通信时钟、MCU 主时钟、任何需要 ppm 级或跨温度稳定的定时、需要精确 50% 占空比的场合（本拓扑典型占空比 41%~45%，且随阈值变）。

频率上下限：

  • 上限 ~1–2 MHz：再高 tpd 和输出摆率开始吃掉周期，杂散电容占比也失控；
  • 下限 ~1 Hz：再低 R·C 就得取到 1 s 以上，R 受漏电流限制、C 受漏电和体积限制。低于 10 Hz 建议用 MCU 定时器或加计数器分频。

提高稳定性的四件事：稳压供电（或用 LDO）、C0G 电容、1% 电阻、样机实测后微调 R（逐台校准）。做完这四件，同一温度下的初始频率一致性可以到 ±5%；但跨温度、跨批次仍是 ±15% 量级——校准只消除初始偏差，消不掉温漂。

平均电流：I ≈ C·VCC·f（每个周期给 C 充一次电）。100 kΩ + 1 nF @3.0 V → 14.4 kHz、约 43 µA；10 kΩ + 1 nF → 144 kHz、约 430 µA。低功耗场合优先大 R 小 C。

5. 三个典型电路

5.1 单键去抖到 GPIO（标准型）

        VCC
         │
       R_p 47 kΩ
         │
   ┌─────┴──────┬─────────────► A  EM74LVC1G17 ──► Y ──► MCU GPIO
   │            │
  SW1          C 0.47 µF
   │            │
  GND          GND
  • τ = 47 kΩ × 0.47 µF = 22.1 ms；按下延迟 24.3 ms（typ）/ 27.1 ms（max），释放 15.3 / 18.6 ms。
  • 1G17 同相 → 按下为低。要「按下为高」换 EM74LVC1G14（反相）。
  • 长线或面板引出：A 前串 100 Ω–1 kΩ，C 端并 TVS 到地。
  • 关掉 MCU 内部上拉，否则 40 kΩ 与 47 kΩ 并联成 21.5 kΩ，τ 从 22 ms 掉到约 10 ms，和设计值差一倍。
  • 施密特输出直连 GPIO，不要再串普通门——多一级普通门就多一个阈值判决点，前功尽弃。

5.2 长按开机 / 单键使能（RC 当定时器）

        VCC
         │
       R 100 kΩ
         │
   ┌─────┴──────┬─────────────► A  EM74LVC1G14 ──► Y ──► /EN（低有效使能）
   │            │
  SW1          C 4.7 µF
   │            │
  R_s 100 Ω    GND
   │
  GND

（R_s 与 SW1 串联，只在按下时限制 C 的放电电流，不影响充电 τ。）

  • 上电时 C = 0，反相器输出高 → 系统关断；按住 SW1 后 C 经 R 充电，越过 VT+ 输出翻低 → 使能。τ = 100 kΩ × 4.7 µF = 470 ms，按住时间 326 ms（typ），264–397 ms（极值）。
  • 松开后 C 经 R_s + 开关快速放电（τ = 0.47 ms），系统立即关断——天然实现「按住才运行」。
  • R_s 必须有：没有它，4.7 µF 通过触点放电的峰值电流只受接触电阻限制，会烧蚀触点。
  • R 不能取 470 kΩ：II·R = 0.47 V，已经超过 VH（0.6 V typ / 0.31 V min），阈值被漏电流顶飞。要更长延时，加 C 而不是加 R（C ≤ 10 µF，再大漏电和体积都不划算）。
  • 这个电路的延时精度就是 §3.5 的 ±15%~±40%，别用它做「精确 2 秒」。

5.3 RC 振荡器（基本型 + 门控型）

基本型（1G14）：

              R = 100 kΩ
        ┌──────────────────┐
        │                  │
        │   ┌──────┐       │
        ├───┤A    Y├───────┴──────► f_out ≈ 14.4 kHz
        │   │ 1G14 │
        │   └──────┘
       ─┴─ C = 1 nF
        │
       GND
  • f = 1.44 / (100 kΩ × 1 nF) = 14.4 kHz（typ @3.0 V）。
  • R 取 10 kΩ–100 kΩ，C 取 1 nF–1 µF。C 低于 500 pF 时杂散电容误差 >3%，不要用。
  • 输出可直驱 LED（串限流电阻）或蜂鸣器三极管基极；±24 mA @3.0 V 的能力够了。

门控型（HCS10，NAND）：

        ┌──────── R = 100 kΩ ────────┐
        │                            │
   ┌────┴─────┐                      │
EN ►┤A         │                      │
   │  B     Y ├──────────────────────┴──► f_out（EN=H 时振荡）
   └────┬─────┘
        │  B = RC 节点
       ─┴─ C = 1 nF
        │
       GND
  • EN = 低 → Y 恒高 → C 充到 VCC 停振，输出静态高；EN = 高 → 起振。
  • HCS10 是三路 NAND，一颗封装可以做三路独立振荡器（或两路 + 一路备用门）。
  • HCS11（AND）极性相反：EN = 低时输出恒低，停振在低电平。
  • 门控端（A）必须是干净的逻辑电平，不能接 RC 节点——那会把 NAND 变成模拟比较器，行为不可预测。
  • HCS 在 4.5 V 时 f ≈ 1.10/(RC)，比同电压的 LVC（1.82）低约 40%——迟滞宽了近一倍，周期自然长。算频率时用 §4.3 的表，别套 1.44。

6. 常见误区

  1. 用普通门做整形：HC04/LVC1G04 没有迟滞，慢边沿 + 噪声 = 多次翻转。这是「按一次跳好几个数」的第一嫌疑。
  2. 只加 C 不加 R：C 直接并在按键上，按下瞬间靠触点给电容放电，峰值电流几十安，触点很快烧黑。必须串 R。
  3. τ 取得比抖动窗口还短：R = 1 kΩ + C = 100 nF → τ = 0.1 ms，对 5 ms 的抖动串毫无作用，只是把边沿变慢、让普通门更容易抖。
  4. 拿 1G17 搭 RC 振荡器：同相缓冲 + R 反馈是正反馈，一上电就锁死在一个状态，不起振。振荡器必须用反相施密特（1G14/HC14）或 NAND 施密特（HCS10）。
  5. 把 RC 振荡器当通信时钟：§4.4 的总误差 −28%/+57%，UART 直接丢帧。要时钟就上晶振或有源振荡器。
  6. 用 typ 阈值算时间：3.0 V 下 t_fall 的极值范围是 0.88τ–1.23τ，typ 1.10τ 只是中间值。批量一致性要求高时必须按极值设计。
  7. 忽略内部上拉并联：外部 47 kΩ + 内部 40 kΩ = 21.5 kΩ，τ 直接减半。调试时「怎么比算的快一倍」多半是这个。
  8. R 取得太大还怪芯片：330 kΩ 上拉 + 1 µA 漏电流 = 0.33 V 偏移，超过 VH，阈值完全跑偏。高阻节点是漏电流和噪声的放大器。
  9. 忽略 C 的 DC-bias：标称 1 µF 的 X7R 在 3.3 V 下可能只剩 0.6 µF，τ 短 40%。定时用途用 C0G，或按降额曲线修正。
  10. 以为频率与电源无关：见 4.3，1.8 V 和 5.5 V 差 1.7 倍。电池供电的振荡器频率会随电量一路漂。

7. 核对清单

通用

  • [ ] 输入信号幅度是否覆盖 VT+ max 与 VT− min，并留 ≥0.3 V 余量
  • [ ] 噪声/纹波峰峰值是否 < VH_min（不是 typ）
  • [ ] 供电域是否匹配（1.8/2.5/3.3 V → LVC；5 V → AHC/HC/HCS）
  • [ ] 极性是否正确（1G14 反相 / 1G17 同相 / HCS10 NAND 反相 / HCS11 AND 同相）
  • [ ] 输出负载电流是否在 ±24 mA（LVC）/ ±6 mA（HCS）以内
  • [ ] 是否核对过 −40~+125 °C 列的 min/max，而不是只看 25 °C typ

去抖

  • [ ] τ 是否 ≥ 9× 单次抖动脉冲宽度（@3.0 V，VH_min 0.31 V）
  • [ ] 总响应（T_b + 1.23τ）是否 ≤ 30 ms
  • [ ] R_p 是否 ≤ 100 kΩ（宽温 ≤ 47 kΩ），II·R 是否 < 0.1·VH_min
  • [ ] 按键与 C 之间是否串了 100 Ω–1 kΩ
  • [ ] MCU 内部上拉是否已关闭，或已并入 τ 计算
  • [ ] C 是否为 C0G/X7R 降额使用，容差是否进预算
  • [ ] 长线/面板引出是否加了串阻 + TVS

振荡器

  • [ ] 是否用了反相施密特（1G17 不行）
  • [ ] f·RC 常数是否按实际 VCC 查表（不是一律 1.44）
  • [ ] C 是否 ≥ 1 nF（杂散占比 <2%）
  • [ ] R 是否在 10 kΩ–100 kΩ（漏电流与输出阻抗的夹缝）
  • [ ] 目标频率是否在 1 Hz–2 MHz 内
  • [ ] 负载是否会让 VOH 掉、VOL 抬（掉了要重算 f）
  • [ ] 是否接受 ±30% 的初始误差，或已安排产线校准
  • [ ] 占空比是否可接受（41%~45%，不是 50%）
