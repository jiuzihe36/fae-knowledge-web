电平转换（Level Translation）选型与应用指导

面向 FAE 与系统工程师。覆盖芯祥四条转换路线：EXS 自动方向、EM74LVC1T45 固定方向（Draft）、LVC8T245 / LVC4245 双电源收发器、LV1T 单电源升压。 参数取自 entities/ 各页实读值；关键指标以对应规格书为准。

1. 先判三件事，再选型

判据 问题 决定
① 方向 信号是单向固定、双向分时，还是开漏总线？ 固定→1T45；分时双向→EXS/8T245；开漏（I²C/1-Wire）→EXS（带内部上拉）
② 电压域 A 侧、B 侧各自多少伏？谁高谁低？ EXS：A 侧 1.3–5.5 V、B 侧 1.65–5.5 V；8T245：两侧各 1.3–5.5 V 独立
③ 速率 推挽多少 Mbps？开漏多少？ EXS 全系封顶 40 Mbps（推挽）/ 2 Mbps（开漏）；要更快只能上 8T245

三条铁律：EXS 没有更快的料（40 Mbps 是上限）；8T245 是 DIR+OE 架构，不是自动方向；1T45 是 Draft，可送样评估、不承诺量产交期。

LVCH 与 LVC 的区别：LVCH 带总线保持（Active bus hold），浮空输入不会漂；原设计省了外部上下拉才用 H 件，LVC ↔ LVCH 只可 H 对 H 替，反过来会丢保持能力。

3. 逐场景选型

3.1 I²C / SMBus / 1-Wire（开漏双向）

  • 首选 EXS0102DC（VSSOP-8L）/ EXS0102GE（DFN-8L，2026-11 新增）：每 I/O 内部 10 kΩ 上拉 + 单稳加速，省外部上拉。
  • 注意：OE 无内部下拉，规格书要求经电阻接 GND；靠 OE 浮空默认关断的板子必须补下拉。
  • 通道不够按位数升级：4 bit → EXS0104，6 bit → EXS0106，8 bit → EXS0108。
  • 开漏速率只有 2 Mbps，I²C Fast-mode Plus（1 Mbps）够用；不要拿 EXS 当 SPI 转换器。

3.2 SPI / QSPI（推挽单向为主）

  • 40 Mbps 以内：EXS0102/0104/0106/0108（自动方向，省 GPIO）。
  • 超过 40 Mbps 或时序预算紧 → 必须换 8T245 路线：EM74LVC8T245PW（或需要总线保持时 EM74LVCH8T245PW）。
  • 8T245 三个必讲差异：① DIR + OE 架构，OE 低有效须下拉/接地，不许浮空；② 封装由 TSSOP-16 变 TSSOP-24（本体 4.4 mm），已 layout 要核改板；③ tpd 最坏 26.3 ns（VCC(A)=1.8 / VCC(B)=3.3，−40~85 ℃），数据率与 tpd 是两个数，别只报 Mbps。
  • 空余通道：A 侧接 GND 或 VCC(A)，B 侧悬空。

3.3 单向固定方向（GPIO、时钟、使能）

  • EM74LVC1T45GV（SOT23-6L）：单 bit、DIR 固定电平即当单向转换器；1.2–5.5 V 两侧独立、ICC ≤16 μA、tpd 5.3 ns（A→B @VCC(B)=3.3 V typ）。
  • 需要更小封装：GW(SOT363) / GS(DFN1×1-6L) / GM(DFN1.45×1-6L) / YZP(BGA1.39×0.89-6B)。
  • Draft 口径：可按 Draft 报型号与参数、可送样，不承诺量产交期；LVCH 版订单尾缀 Draft 未单列，报料前须产品线确认。

3.4 电压域跨度大 / 需要双向总线

  • 8 位双向总线（数据总线、并口）：EM74LVC8T245PW / EM74LVC4245APW。
  • 单电源升压（1.8 V 逻辑驱动 3.3 V/5 V 门电路，不需双向）：LV1T 全系，按功能号选（00 NAND / 02 NOR / 04 反相 / 08 AND / 32 OR / 34 缓冲 / 86 XOR / 87 XNOR / 125·126 三态缓冲）。

4. 接线与设计要点

4.1 EXS 侧

  • VCC(A) 与 VCC(B) 无上电顺序要求（任一侧先上电可）。
  • 未用通道：A/B 两侧接同一电平（VCCI 或 GND），不要单边悬空。
  • 每个电源脚就近 0.1 µF 去耦；OE 经 10 kΩ 下拉到 GND（必须）。

4.2 8T245 侧

  • DIR 决定方向（A→B / B→A），OE 低有效使能；两脚都要确定电平，不许浮空。
  • 总线可能浮空（拔卡、长线）时选 EM74LVCH8T245PW（总线保持）。
  • 方向切换时先拉高 OE 关断输出，再改 DIR，避免两端对驱。

4.3 1T45 侧

  • DIR 接固定电平即可当单向用；DIR 不许浮空（无内部下拉）。
  • 5 V 掉电靠 IOFF 防反灌，但 B 端不要继续被驱动。

5. 常见误区

  1. 把 EXS 当高速转换器：40 Mbps 是硬上限，客户要 100 Mbps 只能改 8T245 架构。
  2. 拿 8T245 顶自动方向件：8T245 需要 DIR 信号，I²C/SDIO 这类每根线双向翻转的总线在架构上不成立。
  3. 只看 Mbps 不看 tpd：8T245 的 26.3 ns 进不了紧时序预算；SPI 读回路要按「半周期 − Flash tCLQV」算。
  4. OE / DIR 浮空：EXS 的 OE 必须下拉；8T245 的 OE、1T45 的 DIR 都必须确定电平。
  5. LVCH 当 LVC 替：带 H 的件每个数据脚要 125 µA~900 µA 过驱动才翻得动，大阻值上下拉或高阻源会失效——H 只对 H。
  6. 1T45 当量产料报：目前 Draft V0.3（2026-10-15），官方目录未列，报交期会翻车。

6. 选型核对清单

  • [ ] 方向：固定 / 分时双向 / 开漏总线
  • [ ] 电压：A、B 两侧实际电压与谁高谁低
  • [ ] 速率：推挽 Mbps / 开漏 kbps，是否 ≤ 40 Mbps
  • [ ] 时序：tpd 是否进预算（8T245 26.3 ns、1T45 5.3 ns typ）
  • [ ] 控制脚：OE / DIR 是否有确定电平，谁提供
  • [ ] 位数与封装：通道数、封装尺寸、是否已 layout
  • [ ] 总线保持：原设计是否依赖内部上下拉（决定 LVC vs LVCH）
  • [ ] 状态：是否 Draft（1T45），能否承诺量产
