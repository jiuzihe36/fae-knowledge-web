移位寄存器与 I/O 扩展 / LED 驱动 选型与应用指导

三件事：输出扩展（595/4094）、输入扩展（165/597）、片选扩展（138）。核心差异只有一个：有没有输出锁存——它决定了你看到的是「干净切换」还是「移位过程中的鬼影」。

1. 型号速查

型号（带尾缀） 功能 电压 关键点 封装
EM74HC595AD / APW 8 位串入 → 串/并出，带输出锁存 2.0–6.0 V 移位寄存器 + 存储寄存器两级；Q7' 可级联 SSOP-16 / TSSOP-16
EM74HC164AD / APW 8 位串入 → 并出，无锁存 2.0–6.0 V 门控串行输入、异步主复位；移位过程输出跟着动 SSOP-14 / TSSOP-14
EM74HC165AD / APW 8 位并入 → 串出 2.0–6.0 V 异步并行置入（PL）、同步串行输入；输入扩展首选 SSOP-16 / TSSOP-16
EM74HC597D / PW（HCT 同档） 8 位并入 + 输入锁存 → 串出 2.8–6.0 V 并行存储寄存器 + 移位寄存器；装载/清零可覆盖 SSOP-16 / TSSOP-16
EM74HC4094D / PW（HCT 同档） 8 位串入 → 并出，带锁存 2.0–6.0 V（HCT 4.5–5.5 V） 与 595 同类但引脚不同；级联用 QS/Q'S SSOP-16 / TSSOP-16
EM74HC138D / PW 3-8 译码器 2.0–6.0 V 低有效输出、三路使能；片选扩展 SSOP-16 / TSSOP-16

595 vs 164：595 有两级寄存器（移位 + 锁存），移位过程中输出不变，RCLK 上升沿才整体更新 → LED/继电器的正确选择；164 没有锁存，移位时输出会逐个乱跳，只适合「移位完再看」或非视觉负载。 595 vs 4094：功能同类，引脚定义不同（4094 有 STR/QS、595 有 RCLK/Q7'），不能直接换 PCB。

2. 典型拓扑

2.1 输出扩展（LED / 继电器 / 数码管）

MCU ──SER──► 595 ──Q7'──► 595 ──Q7'──► …（级联 N 片）
      ──SRCLK─► 并联到所有片
      ──RCLK──► 并联到所有片（锁存）
      ──OE────► 接地（低有效使能；拉高=高阻）
  • 级联 N 片 = N×8 路输出，MCU 只占 3 根线（SER/SRCLK/RCLK）。
  • OE 必须接地（595 的 OE 高电平 = 输出高阻），不要悬空。
  • 上电默认态：595 上电输出为 0（寄存器清零），需要「上电高」的负载要外加反相或上拉。

2.2 输入扩展（拨码 / 按键阵列 / 多路状态回读）

多路输入 ──► 165（PL 并行置入）──QH──► MCU MISO
             ▲ SH/LD 控制装载，CLK 移位
  • 165 的 PL 低有效装载；装载后逐位移出，先移出 H 还是 A 取决于器件定义，按规格书时序表。
  • 需要「输入先锁存再移位」时用 597（并行存储寄存器），适合输入会变化的场景。

2.3 片选/地址扩展

  • EM74HC138D：3 根地址 → 8 个低有效片选；E1/E2/E3 使能做 bank 扩展。
  • 多片 138 级联 = 3+3 根线扩 64 个片选。

3. 设计要点

  1. 限流电阻：LED 每路串 R = (VCC − VF) / I_LED；按整片总电流核算（查规格书绝对最大额定值与功耗）。
  2. 级联时序：SRCLK 与数据在同一边沿采样（595 是上升沿移位），长线时数据要在时钟沿前稳定（setup 时间见动态表）。
  3. RCLK 与 SRCLK 分开走线：RCLK 是锁存脉冲，和 SRCLK 并行会引入抖动；两者都要远离模拟/射频走线。
  4. 长线驱动：MCU 到第一片的 SER/SRCLK 串 33–100 Ω，抑制反射；超过 30 cm 建议加缓冲。
  5. 多片并联的时钟负载：每片输入电容累加，N 片后 SRCLK 边沿变慢，必要时加 EM74LVC1G17GV 缓冲。
  6. OE 用法：595 的 OE 可接 PWM 做整体调光（低频 PWM），但注意 OE 关断时输出是高阻不是低电平。

4. 常见误区

  1. 用 164 驱 LED 做「流水灯」：无锁存 → 移位过程中鬼影，观感是「乱的」。正确用 595 + RCLK。
  2. 595 的 OE 悬空：输出可能高阻，表现为「有时候亮有时候不亮」。
  3. 595 与 4094 直接互换：功能同类但引脚不同，直插会错连。
  4. 级联时忘记接 Q7'：595 级联要接 Q7'（不是 Q7），否则第二片数据不对。
  5. 忽略总电流：8 路 LED 全亮时整片电流可能超规格书限值，要按 DC 表与 Ptot 核算。
  6. 165 的 PL 与 CLK 时序搞反：先置入再移位，PL 低电平期间不能给 CLK。

5. 选型核对清单

  • [ ] 输出还是输入扩展（595/4094 vs 165/597）
  • [ ] 是否需要输出锁存（要 → 595/4094；不要 → 164）
  • [ ] 位数与级联片数（N×8）
  • [ ] 供电域（2–6 V HC；5 V 系统可用 HCT；1.8/3.3 V 需另选 LVC 系列）
  • [ ] 负载电流与总功耗（LED/继电器）
  • [ ] 控制线数量与 MCU 引脚预算（3 线 vs 并口）
  • [ ] 上电默认态要求（595 上电为 0）
