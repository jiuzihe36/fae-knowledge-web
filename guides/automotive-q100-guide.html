车规 AEC-Q100 应用指南

面向 FAE 与系统工程师。芯祥在册的车规料只有两颗：EMS3157GW-Q100（单 SPDT）与 EMS23157MS-Q100（双 SPDT），且两份规格书都是 Draft。本文只回答三件事：客户问车规怎么答、料怎么选、样怎么送。 参数取自实体页与 Draft 规格书；关键指标以正式版规格书为准。

1. 车规料清单（截至 2026-11，全部为 Draft）

型号 功能 通道 电压 关键指标 温度 封装 / SPQ 文档状态
EMS3157GW-Q100 单 SPDT 模拟开关，True Isolation 1×SPDT 1.5–5.5 V RON 1.9 Ω @5.5 V；BW 800 MHz；OIRR −80 dB @10 kHz；XTALK −82 dB @10 kHz；ICC <1 µA −40~+125 °C SOT363 2.1×1.25 mm / 3000 pcs Draft V0.92（10 页）
EMS23157MS-Q100 双 SPDT 模拟开关，True Isolation 2×SPDT 1.5–5.5 V RON 1.9 Ω @5.5 V；BW 800 MHz；OIRR −80 dB @10 kHz；XTALK −82 dB @10 kHz；ICC <1 µA；标注适合 USB2.0 High-Speed 路由 −40~+125 °C MSOP-10L 3.0×3.0 mm / 3000 pcs Draft V0.9（9 页）

两颗均按 AEC-Q100 Grade 1 口径：EMS3157-Q100 规格书 p1 明确写 "AEC-Q100 Grade 1"；EMS23157-Q100 在公司对外口径中同列 Grade 1，规格书 Recommended Operating Conditions 的 Tamb 均为 −40~+125 °C。

在册口径（对外只认这几条）

  • 在册车规料只有这两颗。客户报任何其它料号——标准版 [[ems3157]] / [[ems23157]]、USB/HDMI 开关、电平转换、74 逻辑、负载开关——一律答 「无车规版本，转产品线评估」，不接参数讨论、不承诺"可以做车规"。
  • 两颗均为 Draft：规格书仍为草稿、量产前须确认。可送样评估，不承诺量产交期与价格。
  • 标准版与 Q100 版是两套文档：EMS3157 标准版 V1.8 / Q100 版 V0.92；EMS23157 标准版 V1.3 / Q100 版 V0.9。参数不可互套，报料必须带 -Q100 尾缀。
  • 车规身份落在完整订购号上：EMS3157GW-Q100（SOT363，丝印 7Q+YW）、EMS23157MS-Q100（MSOP-10L，丝印 23157Q+XYYWW）。

2. AEC-Q100 到底是什么

2.1 定义：一份应力测试标准，不是一张证书

AEC-Q100 是汽车电子委员会（AEC）发布的车用封装集成电路应力测试认证标准，全称 "Failure Mechanism Based Stress Test Qualification for Packaged Integrated Circuits"。三个要点：

  1. 它是基于失效机理的应力试验标准，不是安规认证、不是第三方证书，也没有"证书编号"。供应商按标准完成试验并出具 qualification 报告，客户审核承认。
  2. 它只管封装 IC；分立器件、被动件分别走 AEC-Q101 / AEC-Q200，不要混用。
  3. "通过 AEC-Q100" 必须带 Grade 与报告范围；只讲"车规"不算证据。

2.2 Grade：按环境工作温度分四档

Grade 环境工作温度范围（Ta） 常见安装位置（经验）
Grade 0 −40~+150 °C 发动机舱、逆变器/动力总成
Grade 1 −40~+125 °C 底盘、BMS、域控、ADAS、座舱热区
Grade 2 −40~+105 °C 车身控制、HVAC、仪表
Grade 3 −40~+85 °C 座舱/信息娱乐等热环境可控处

Grade 是任务剖面分档，不是质量好坏等级。 Grade 2 的件不能顶 Grade 1 的应用，哪怕台架上"看起来能用"。旧版曾列 Grade 4（0~+70 °C），Rev-H 起已取消，现在不要报 Grade 4。

2.3 AEC-Q100 看哪些试验（与公司 8 项口径对照）

应力项 考什么 公司质量考核口径（对外可写）
HTOL 高温工作寿命、长期失效机理 125 °C / 1000 h，3 lots
TC 温度循环、焊点与界面疲劳 −65~150 °C / 500 cycles，3 lots
HAST 湿热偏压 130 °C / 85%RH / 96 h，3 lots
HTSL 高温存储 150 °C / 1000 h，3 lots
PreCon 预处理 + 回流 Bake 125 °C 24 h → 85 °C/85%RH 168 h → 回流 3×260 °C
ELFR 早期寿命失效率 125 °C / 48 h，800 pcs
ESD 静电放电 HBM 8 kV / CDM 2 kV
Latch-up 闩锁 25/125 °C，250 mA

AEC-Q100 的完整试验矩阵比这 8 项更多。公司 8 项是可对外说明的质量考核口径，不能当作某颗料的完整 Q100 报告；同名项目也不等于同一份报告，对客户只报报告里实际有的条件、样本数与结论。

3. 车规料与消费料的差异，在客户侧意味着什么

3.1 温度：不是"标到 125 °C"，而是全温区有保证

  • 消费/工业常见 0~70 °C 或 −40~85 °C；Grade 1 是 −40~125 °C 环境温度，比常见工业级（−40~85 °C）高 40 °C，对应座舱热区、底盘、BMS、域控等位置。
  • 客户审表看全温区列，不是 25 °C Typ。EMS3157-Q100 Draft 给的是双温列：RON @5.5 V 为 Typ 1.9 Ω（25 °C）、Max 3.0 Ω（−40~85 °C 列）、Max 3.5 Ω（−40~125 °C 列）；tON/tOFF Max 从 600/200 ns（−40~85 °C 列）升到 650/250 ns（−40~125 °C 列）；tBBM Max 从 1000 ns 升到 1100 ns。
  • EMS23157-Q100 Draft V0.9 的 DC 表只有 25 °C 单列，AC 表仅给 Typ、无温度列与 Max。客户若要 −40~125 °C 的 AC 保证，先向产品线取完整数据，不能把 Typ 当 Max 报。这是两颗料目前在证据上的主要差异。
  • 设计余量按 125 °C Max 算：RON 上升直接影响音频插损、增益误差与信号幅度；tON/tBBM 影响切换时序与 pop 噪声。

3.2 认证与证据：客户要的是报告包

  • 车规客户（Tier1/车厂）通常要：AEC-Q100 qualification report（应力项、条件、样本数、lot 数、判据）、ESD/latch-up 报告、可靠性总结、材料声明（IMDS/RoHS/REACH）、PCN 变更通知、批次追溯。
  • 器件页现有：EMS3157-Q100 列 ESD HBM JS-001 Class 2 >3000 V、CDM JS-002 Class C3 >2000 V、Latch-up >200 mA；EMS23157-Q100 的 Draft 特性页没有 ESD/latch-up 数值，报客户前向产品线取报告，不要拿同系列 3157 的数套用。
  • 公司质量考核 8 项（HTOL/TC/HAST/HTSL/PreCon/ELFR/ESD/Latch-up，条件见 2.3）是能力口径，不是单颗料的 Q100 报告。两套 ESD 数字——器件页 Class 2/C3 与考核口径 8 kV/2 kV——不要混着报，对外按器件页规格书写。
  • 体系：对外口径是 ISO 9001；IATF 16949 未见对外表述，客户体系审核问到时转质量部门，不自行承诺。
  • 对外话术只能是"部分产品通过 AEC-Q100 Grade 1"，不能说"全线车规"。

3.3 PPAP：Draft 阶段签不了

  • PPAP（Production Part Approval Process）是量产放行文件包，AIAG 口径含 18 项要素（设计记录、PFMEA、控制计划、MSA、尺寸报告、材料/性能试验、初始过程研究、PSW 等），客户按 Level 提交，常用 Level 3。
  • 客户侧含义：没有 PPAP 就没有量产承认；PPAP 的前提是量产件、固化 BOM、固化工艺。
  • 对 Draft 料的正确答复：现阶段只到"样品 + Draft 规格书 + 已有测试报告"，不签 PPAP 承诺、不报提交等级；设计冻结后由产品线/质量按客户等级准备。
  • 时间线讲清楚：样品评估 → 设计冻结 → 量产件 → PPAP 批准 → SOP。任何一段都不能拿 Draft 文档当量产依据。

4. 选型与送样流程

4.1 五步选型

  1. 定功能：单路 SPDT（3157）还是双路 SPDT（23157）；是否需要 True Isolation、break-before-make。
  2. 定信号：音频/视频/UART/USB2.0 路由；信号幅度 ≤ VCC，控制脚 1.8 V 兼容。
  3. 定温度：安装位置环境温度 → Grade 1（−40~125 °C）是否覆盖；超 125 °C 无在册料，转产品线评估。
  4. 定封装：SOT363（2.1×1.25 mm）还是 MSOP-10L（3.0×3.0 mm）；SPQ 均 3000 pcs；核对丝印。
  5. 定状态：Draft V0.92 / V0.9，按"可送样评估、规格书仍为草稿、量产前须确认"口径报。

4.2 送样流程

  1. 客户给出应用、信号类型、电压/温度/封装、年用量、项目节点。
  2. FAE 核对是否在册两颗之内；不在册 → 「无车规版本，转产品线评估」，登记需求反馈产品线。
  3. 在册 → 出 Draft 规格书 + 已有测试报告，明确 Draft 状态与量产前确认项。
  4. 走销售/FAE 样品流程；样品型号必须带 -Q100 完整订购号，不给标准版样品。
  5. 客户评估通过 → 设计冻结 → 产品线确认正式版规格书、交期、价格、PPAP 等级 → 量产。

4.3 客户问答口径

客户问 标准答法
"这颗有车规版吗？" 在册车规料只有 EMS3157GW-Q100、EMS23157MS-Q100 两颗模拟开关；您这颗不在册，无车规版本，转产品线评估。
"Q100 是 Grade 几？" 在册两颗按 Grade 1（−40~+125 °C）；规格书仍是草稿、量产前须确认。
"能量产交货吗？" 现阶段可送样评估；量产前须确认正式版规格书、交期与价格。
"有 PPAP / IATF 16949 吗？" Draft 阶段不签 PPAP、不报提交等级；体系口径为 ISO 9001，IATF 与 PPAP 转质量/产品线确认。
"和标准版参数一样吗？" 功能同族，但文档与订购号不同；车规参数以 -Q100 Draft 规格书为准，不能套标准版。

5. 常见误区

  1. 拿消费级/工业级料顶车规：标准版 [[ems3157]] / [[ems23157]] 参数再好也不是 Q100 件；"同一 die、只是封测不同"不能作为交付依据，没有 Q100 报告与 -Q100 订购号就不是车规料。
  2. 以为 Q100 只是温度不同：Grade 只是温度分档；Q100 还包含应力试验矩阵、样本/lot 要求与随附报告。只改标称温度 = 假车规。
  3. 把 Draft 当量产料报：两颗都是 Draft（V0.92 / V0.9），规格书仍为草稿、量产前须确认；报交期/价格/PPAP 会翻车。
  4. 用 Typ 顶 Max：EMS23157-Q100 Draft 的 AC 表只有 Typ；在拿到全温区数据前，不能用 25 °C Typ 代替 125 °C Max 做设计承诺。
  5. 把 Q100 当 ISO 26262 功能安全认证：Q100 证明可靠性，不等于 ASIL 能力；客户要 ASIL/功能安全资料，转产品线/质量。
  6. 把"部分产品通过"说成"全线车规"：公司口径只在册两颗；74 逻辑、电平转换、其它模拟开关一律无车规版本，转产品线评估。
  7. 混用标准版与 Q100 文档：报料带 -Q100 尾缀；引用页码/参数前先确认是哪一版（V1.8 vs V0.92、V1.3 vs V0.9）。
  8. 混报两套 ESD 口径：器件页是 HBM Class 2 >3000 V / CDM C3 >2000 V（仅 3157 列）；公司考核口径是 HBM 8 kV / CDM 2 kV。对外按器件页，测试能力问题转质量。

6. 核对清单

料号与状态

  • [ ] 订购号是否 -Q100 尾缀且在册（EMS3157GW-Q100 / EMS23157MS-Q100）
  • [ ] 不在册是否已答「无车规版本，转产品线评估」并登记需求
  • [ ] 是否说明 Draft：「规格书仍为草稿、量产前须确认」

温度与参数

  • [ ] 安装位置环境温度是否 ≤ +125 °C（Grade 1）
  • [ ] RON / tON / tOFF / tBBM 是否按 125 °C Max 核算
  • [ ] 23157 的 AC 数据是否已向产品线取全温区值（不得用 Typ 顶 Max）

电气与封装

  • [ ] VCC 1.5–5.5 V、信号 ≤ VCC、控制 1.8 V 兼容
  • [ ] 单/双 SPDT、True Isolation、break-before-make 是否匹配
  • [ ] 封装 SOT363 / MSOP-10L、丝印、SPQ 3000 是否核对

证据与商务

  • [ ] ESD / latch-up / 可靠性报告是否齐（23157 必查）
  • [ ] 是否只讲"部分产品通过"，未扩大为全线车规
  • [ ] 交期/价格/PPAP 等级/IATF 是否转销售与质量，未口头承诺
