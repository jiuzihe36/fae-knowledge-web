EMS 模拟开关（Analog Switch）产品选型与应用指导

面向 FAE 与系统工程师的应用手册。本文档基于芯祥（EM）EMS 数据手册库（~/wiki/entities、原始 JSON 抽取值）编制，覆盖特征参数、功能分类、选型流程与典型应用接线。

1. 产品线总览

EMS 系列是芯祥的模拟开关 / USB 数据开关 / 音频开关产品线，覆盖高速 USB2.0/3.x 信号路由、音频 HiFi 负压摆幅开关、以及通用低压模拟开关（SPDT/DPDT/SPST/PST）。按功能可划为五大族：

族 代表型号 核心能力 常见封装
USB2.0 Mux/DeMux [[ems4310]] EMS4310、[[ems4000]]/[[ems4002]]、[[ems3412]] 2:1/双2:1，USB2.0 hi-speed，多带 20V OVP QFN、DFN、MSOP
USB3.x 高速 Mux [[ems4422]]、[[ems4100]] USB3.0/3.1 10Gbps + HDMI2.1（宣称兼容） QFN
USB/音频负压摆幅开关 [[ems4321]]/[[ems4320]]、[[ems3218]] HiFi Audio + UART + USB2.0，负压/过压保护 QFN1.4x1.8-10
通用低压模拟开关 [[ems3157]]、[[ems2750]]、[[ems3218]]、[[ems4567]] 低压 SPDT/DPDT，True Isolation，1.x–5.5V SOT、DFN、QFN、MSOP
耗尽型隔离开关（音频） [[ems3550]]、[[ems3580]]、[[ems3515]] 负压摆幅、pop/click 消除、HiFi QFN、WLCSP、DFN

快速记忆：EMS77XX（如 [[ems7227]]）= 双端口 USB2.0 UART 开关；EMS44XX（如 [[ems4485]]）= USB Type-C 音频/保护开关。EMS 系列另有车规 Q100 后缀（如 [[ems23157-q100]]、[[ems3157-q100]]），仅车上使用。

2. 核心电气参数解读

选型时优先锁定 5 个参数，其余查数据手册。

2.1 导通电阻 Ron（Ω）

Ron 决定信号路径压降与衰减。Ron 越小越适用于低阻抗/高速信号，音频与 USB 高速均追求低 Ron。典型值分布：

  • 超低 Ron 高速/多数开关：[[ems4321]] Ron≈0.9 Ω、[[ems3902]]/[[ems3900]] Ron≈1.9 Ω、[[ems23157]]/[[ems2750]] Ron≈1.9 Ω
  • 准电阻（低 Ron）开关：[[ems4899]]/[[ems4567]]（Quad SPDT，RON≈1.9 Ω）
  • 高阻隔离型（耗尽型单刀）：[[ems3550]] RON≈1.2 Ω、[[ems3515]]/[[ems3518]]（负压耗尽型）

注意：部分数据页把 Ron 表为 “RON = x Ω @ VCC”，请按对应电源电压读取；封装后缀不影响 Ron。

2.2 带宽 / 数据速率

开关的 -3dB 带宽决定可承载的信号速率：

信号 最低带宽参考 达标型号示例
USB2.0 (480Mbps) hi-speed ~400–800 MHz [[ems4310]]、[[ems3900]]、[[ems4735]]
USB3.0 / 3.1 (5–10Gbps) ≥ 5–10 GHz [[ems4100]]（SuperSpeed 10G）;[[ems3412]]/[[ems4310]]（5.1GHz）
HDMI2.1 5.7 GHz（-3dB，宣称兼容 HDMI2.1） [[ems4422]]
音频（HiFi） 无需高速，看重负压摆幅 [[ems3218]]、[[ems4320]]

例：[[ems3902]] 标称 "High Bandwidth (-3 dB @ 800 MHz) Suitable For USB2.0"，即明确面向 USB2.0 hi-speed 路由。

2.3 负压摆幅能力（Negative Swing）

音频信号常带负压。若开关不支持负压摆幅，负向音频会被削波。带 "Negative Swing Capability" 的型号：[[ems4320]]/[[ems4321]]、[[ems3218]]、[[ems3515]]/[[ems3518]]/[[ems3550]]、[[ems3580]]。选音频开关务必核对此项。

2.4 隔离度（Isolation）

  • True Isolation（真隔离）：断电时切断信号路径，防止串扰回灌。[[ems23157]]/[[ems2750]] 等 Low Voltage High Speed 系列带此特性。
  • 隔离度数值（dB）越高串扰越小，多路复用场景看低频隔离度。

2.5 过压保护（OVP）与 ESD

  • 20V OVP：[[ems4000]]/[[ems4002]]（Dual 2:1 USB2.0 with 20V OVP）。注意命名中的"20V"实为 IEC 61000-4-5 浪涌耐受 ±20V（C0± 无外加 TVS）；OVP 关断本身是 DC 7V（上升沿锁存阈值 4.6–5.2V），选型时按 VBUS 过压场景核对。
  • ESD 等级：高速 USB 开关标称 HBM/CDM，如 [[ems7227]] HBM 8 kV（power/GND 更高，>16 kV）。选消费/车载端口按系统 ESD 目标对齐。

3. 功能分类与选型流程

按应用场景选型流程：

  1. 定信号类型：USB2.0 / USB3.x / 音频 / 通用模拟 / UART。
  2. 定拓扑：SPDT / DPDT / SPST / 4:1 / 2:1 Mux / Depletion 隔离。
  3. 定电源与电平：核对 VCC 范围（1.5–5.5V 通用；负压摆幅型号看 VSW 范围）。
  4. 定通道与封装：按 PCB 面积 → QFN/DFN/WLCSP；按焊接难度 → MSOP/SOT。
  5. 核对特殊需求：OVP、ESD、pop/click 消除、防潮检测（[[ems4485]]）。

3.1 通用模拟开关（SPDT/DPDT）

  • 双 SPDT 真隔离：[[ems23157]]、[[ems2750]]、[[ems3905]]（Low Voltage High Speed）
  • 单 SPDT：[[ems3157]]、[[ems3157-q100]]（车规）
  • Quad SPDT 低阻：[[ems4899]]、[[ems4567]]
  • 应用于：音频路由、测试装备 mux、负压视频、信号采样切换。

3.2 USB2.0 数据开关

  • 双 2:1 Mux/DeMux +20V OVP：[[ems4000]]、[[ems4002]]
  • 2:1 USB2.0+USB3.0：[[ems3412]]（QFN4x4-24）、[[ems4310]]（QFN4x4-24）
  • 双 USB2.0 DPDT：[[ems3900]]、[[ems3902]]
  • USB Type-C 音频+USB 复用：[[ems4320]]、[[ems4321]]
  • 双 4:1 USB2.0（480M）SPQT：[[ems4735]]
  • 用于：多端口 USB 选择、Type-C 引脚复用、OTG 路由。

3.3 USB3.x / 高速差分

  • Two Channel 差分 2:1/1:2 SuperSpeed 10G Mux：[[ems4100]]
  • HDMI2.1 开关：[[ems4422]]
  • 用于：USB-C 高速数据、HDMI 2.1 信号切换、高带宽差分路由。

3.4 音频开关（负压摆幅 / 负极隔离）

  • HiFi SPDT pop/click 消除：[[ems3580]]（Stereo SPDT with Pop and Click Elimination）
  • 4-PST 耗尽型隔离：[[ems3550]]
  • 负压摆幅 HiFi Audio/UART：[[ems4320]]、[[ems4321]]
  • 双 5V SPST 耗尽音频：[[ems3518]]
  • 用于：耳机音频复用、Audio Jack 检测（带检测功能见 [[ems4485]]、[[ems4798]]）。

5. 典型应用接线示意

5.1 USB2.0 双路复用（host 选择）

         ┌─────────────┐
 D+/D- ──┤ IN1      ──┤── D+/D- (to SoC/USB PHY)
 D+/D- ──┤ IN2       ─┤
         │ USB-C 开关   │   SEL = 选择 IN1/IN2
 CLK ───[ SEL ]         │   EN  = 使能
         └─────┬───────┘
               │ VCC (1.5–5.5V)

选用 [[ems3412]]/[[ems4310]]/[[ems4000]] 系列。注意给 SEL/EN 上拉/下拉确定默认通道，并就近放置 0.1µF VCC 去耦。

5.2 音频负压摆幅（耳机 HiFi 开关）

                 ┌──────────┐
 L / R headset ──┤ S1a  COM │──► 音频 CODEC（HiFi）
 Jack          ──┤ S1b  COM │
 mic          ───┤          │
                  └──────────┘
  VCC 支持负压摆幅（见 -0.3~VCC 规格）

选用 [[ems4320]]/[[ems4321]]/[[ems3580]]。务必确认信号摆幅落在负压规格内，避免削波。

5.3 USB Type-C 音频 + 数据复用（[[ems4485]]）

 Type-C CC/音频线 ──► [[ems4485]]（WLCSP-25）
    │              ├─► USB2.0 数据路径（如可用）
    │              └─► Analog Audio（含 Moisture/Audio Jack 检测）
 带耳机插入/拔出检测，向系统报告音频插拔与防潮状态。

5.4 通用多通道 mux（数据采集/测试）

 多路传感器 ──► [[ems4899]] Quad SPDT / [[ems4567]]
                 │  按 GPIO 选通道逐一接入 ADC
 实现低 Ron 低串扰的模拟前端切换。

6. 选型核对清单（Checklist）

  • [ ] 信号类型匹配：USB2.0 / USB3.x / 音频 / 通用
  • [ ] 拓扑匹配：SPDT / DPDT / Mux / Depletion
  • [ ] VCC 覆盖系统供电（核对最高 VCC 与 VSW）
  • [ ] 时钟/带宽满足数据速率（USB hi-speed→≥400MHz 带宽）
  • [ ] 负压摆幅型号用于音频负压信号
  • [ ] 隔离度/串扰满足系统指标
  • [ ] OVP/ESD 满足端口抗压需求
  • [ ] 封装与 PCB 面积、焊接工艺匹配
  • [ ] 车规需求（AEC-Q100）选 Q100 后缀型号

7. 常见误区

  1. 把 "Negative Swing" 当模拟正负双电源：负压摆幅指允许信号负向摆动的能力，不代表双电源工作。
  2. 只看 Ron 忽略带宽：低 Ron 未必高带宽，USB3.x 需同时查带宽/Gbps 指标。
  3. 音频选了不支持负摆幅的开关 → 负向信号削波/失真。
  4. 忽略锁存/电流回灌：耗尽型负压开关（如 [[ems3515]]）用于隔离负压路径，不要在普通 USB 开关上硬接负压。
  5. 车规与消费不分：车上用 Q100 版本（[[ems23157-q100]]），消费用无后缀版本。
